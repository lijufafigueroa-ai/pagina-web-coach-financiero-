# Mi Coach Financiero Virtual

App de bienestar financiero en HTML, CSS y JavaScript puro (módulos ES).

## Cómo abrirla
1. Abre esta carpeta en Visual Studio Code.
2. Clic derecho en `index.html` → **Open with Live Server** (Go Live).

> Usa Live Server: los módulos JavaScript no funcionan abriendo el archivo con doble clic.

## Estructura
```
index.html              Estructura (HTML semántico)
css/
  main.css              Importa todos los estilos
  variables.css         Colores y tokens
  base.css              Reset y formularios
  layout.css            Header, nav, grids, footer
  components.css        Botones, tarjetas, chips, tablas, toast
  sections.css          Hero y títulos de sección
js/
  main.js               Punto de entrada
  data/frases.js        Frases motivadoras y perfiles
  utils/                storage, dom, format, toast
  modules/              navigation, diagnostico, metas,
                        simulador, bitacora, recordatorios
```
